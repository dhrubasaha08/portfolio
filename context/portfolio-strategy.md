# Animated 2D Space Journey Strategy

## Objective

Position Dhruba Saha as a software engineer in Germany with current, substantial work across backend systems, workflow automation, internal tools, and selective applied AI. Give hiring managers and collaborators enough concrete information to understand how he approaches unclear operational problems and turns them into dependable software.

## Visual direction

Preserve and refine the memorable authored qualities of the original portfolio:

- A continuous deep-space journey built from the original layered stars, planets, sun, mountains, and crater.
- Authored section-owned SVG illustrations that move with each chapter's native-scroll progress.
- One high-detail astronaut as the only three-dimensional object and a supporting accent outside the hero.
- Oversized identity, asymmetric full-width editorial compositions, real project evidence, generous spacing, and simple rules.
- The original deep navy, blue, turquoise, amber, orange, and warm-white color family.
- Self-hosted Montserrat with no remote font requests.
- Native scroll-driven decorative depth without pinned sections, captured touch input, or a nested page-scroll container.

Avoid product dashboards, repetitive interface panels, numbered controls, telemetry, neural-node imagery, fabricated machinery, symbolic dioramas, gradient text, and generated-looking decoration.

## Release standard

The first screen must communicate Dhruba's name, software-engineering identity, Germany location, and current focus before WebGL loads. Every claim must be evidence-backed or explicitly approved, every navigation path must work without decorative effects, and accessibility or data-saving fallbacks must preserve the complete content.

Every semantic chapter owns one decorative `aria-hidden` artwork composition. Motion may affect only those decorative layers; headings, paragraphs, evidence links, and focus targets remain on the native document path without extra transforms.
